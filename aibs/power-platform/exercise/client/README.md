## Evidence contract

Cite a file plus its record or clause ID, for example `04-policy-extract.md#POL-F03` or `03-baseline.csv:FIN-005`. Preserve source version and run ID. Distinguish **fact within this fictional scenario**, **assumption**, **target**, and **unknown**.

Record execution mode as `desk`, `simulation` or `live-sandbox`. A supplied CSV, proposed control, chat response or screenshot is not proof of a real write, permission boundary or enforced release gate. Live runs need tool output and target-system read-back. Never use production data or credentials for this exercise.

Participant templates are intentionally unapproved. Fill their empty fields, obtain human decisions where needed and preserve revisions. The facilitator keeps a separate answer key and holdout set outside this client folder. Do not use holdout cases to tune.

## HVE decisions and observed reuse

Start with the [HVE field sheet](10-output-templates/hve-field-sheet.md): choose partner-led delivery or customer CoE enablement, name the decider, set a maximum wait and commit one person to an observable action inside 48 hours.

Use the [platform decision record](10-output-templates/platform-decision-record.md) to check actual type-specific support, availability, version, scope and observation date. Do not transfer a canvas-app control or release assumption to a different app type without evidence. `artifact_kind` classifies the synthetic inventory; `real_support_state=unknown_verify` means actual support is unverified.

The [agent decision record](10-output-templates/agent-decision-record.md) keeps four decisions with a person: general knowledge, allowed knowledge/tools, unattended/customer-facing scope, and the definition of right with a named rerun owner.

Version and expire control artifacts; attach scoped constraints to every executor call and retain returned ACK evidence. Never invent a result from a blocked plugin. Observe the receiving owner running the harness, then test individually named reuse and comparable effort on a second engagement using the [asset record](10-output-templates/asset-record.md). Desk success is not production transfer.
