# Partner Zero execution play book

The Partner Zero Execution Playbook is a practical 30-day, internal-first method to adopt Copilot Cowork and Copilot Code, establish governance and cost control, and make a Day-30 scale/adjust/stop decision using measured outcomes.

Detailed step guidance is maintained here: **[Partner Zero detailed steps](./detailed-steps.md)**.

## Step overview

| Phase | Days | Step | Summary | Detail |
|---|---|---|---|---|
| Control | 1–10 | 1. Inventory entitlements | Confirm available benefits, seats, credits, and expiry. | [Step detail](./detailed-steps.md#control-step-1-inventory-entitlements) |
| Control | 1–10 | 2. Redeem & assign licences | Redeem base/Copilot licences and assign pilot groups. | [Step detail](./detailed-steps.md#control-step-2-redeem--assign-licences) |
| Control | 1–10 | 3. Fund the gap | Use benefits first; set controlled PAYG for shortfall. | [Step detail](./detailed-steps.md#control-step-3-fund-the-gap) |
| Control | 1–10 | 4. Name owners & set response | Define owners, escalation path, and review rhythm. | [Step detail](./detailed-steps.md#control-step-4-name-owners--set-the-response) |
| Control | 1–10 | 5. Configure access | Enable Cowork and Code access for pilot groups. | [Step detail](./detailed-steps.md#control-step-5-configure-access) |
| Control | 1–10 | 6. Set guardrails | Configure limits, alerts, access boundaries, and data checks. | [Step detail](./detailed-steps.md#control-step-6-set-guardrails) |
