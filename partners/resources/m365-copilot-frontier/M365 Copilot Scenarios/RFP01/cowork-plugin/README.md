# FC RFP Processing Cowork plugin

This is the Microsoft 365 app-package source for the Frontier Consultancy RFP Processing plugin for Copilot Cowork. It combines:

- the `rfp-processing` Agent Skill;
- the public Microsoft Learn MCP server at `https://learn.microsoft.com/api/mcp`;
- a workflow that keeps the RFP wiki in a user-selected OneDrive or SharePoint folder so the review team can work from the same source of truth.

The skill was created by [Joris Kalz](https://www.linkedin.com/in/joris-kalz/) and adapted for Cowork collaboration in Frontier Consultancy.

## Build the uploadable package

The ready-to-install package is checked in as [`fc-rfp-processing-cowork.zip`](fc-rfp-processing-cowork.zip). Most participants should download that file and continue to **Install in Cowork**.

To regenerate the package from source, run the build script from this folder on Windows PowerShell:

```powershell
.\build-plugin.ps1
```

The script validates the expected source files, generates the required PNG icons, and replaces:

```text
fc-rfp-processing-cowork.zip
```

The ZIP contents are rooted at `manifest.json`, as required by the Microsoft 365 app-package format.

## Install in Cowork

1. Open **Copilot Cowork**.
2. Select **+ > Customize > Plugins**.
3. Select **Upload plugin**.
4. Choose the downloaded `fc-rfp-processing-cowork.zip`.
5. Keep it private for testing, or share it with named review-team members.
6. Start a new Cowork conversation and enable **FC RFP Processing** in **Sources & Skills**.

For the complete participant setup, including the shared wiki folder and Zava sample pack, see the [setup guide](../rfp-setup-overview.md).
