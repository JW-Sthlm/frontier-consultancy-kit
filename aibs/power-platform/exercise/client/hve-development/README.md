# Client evidence for feature and schema decisions

**HVE-DECISIONS-1.0. All interviews, proposals, changes and review findings are fictional.**

Use these with [ZAVA-PP-2.0 policy/examples](../offerings/README.md). They replace the earlier implementation/property/debugging baselines in the core.

## How to read a case

- **F facts:** client interview evidence, constraints and unanswered needs.
- **P proposals:** candidate choices to examine, not an approved design.
- **C changes:** new requirements whose scope/data consequences need a human decision.
- **T findings:** supplied walkthrough feedback on a candidate model, not executed application tests.

Original policy remains authoritative. A future request is not automatically accepted scope. CSV examples are not a normalized schema. Do not inherit a table list from earlier maker material or treat more entities as a better answer.
