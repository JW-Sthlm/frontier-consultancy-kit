Copilot for Frontier Consultancy – Scenario Test Guide

Test data, ready-to-paste Copilot Cowork, Code and Skills prompts and expected results for the 14 scenarios in the deck
Do not distribute – draft only

Before you start – set up the test data

  1. One folder. Create a OneDrive folder named Frontier Test Pack and put every test file in it: the Word and Excel documents, plus the subfolders 01 Emails, 02 Meeting transcripts, 03 Teams channel and 04 Data extracts. Copilot finds the files most reliably when they're all in one place.
  2. Emails. The 22 test emails are .eml files. Either drag them into an Outlook folder named Frontier Test, or ask Copilot to send them to your own mailbox with a [TEST] subject prefix. Every email says “Fictitious test data”.
  3. Transcripts. The .vtt files stand in for Teams meeting transcripts. Copilot reads them as files, so the prompts below refer to them by name. To test the transcript trigger in PM 03 for real, hold a short Teams test meeting with “ZAV-HZN” in the title and record it.
  4. Safety. All companies, people, figures and email addresses are made up (.example domains). Keep every outgoing action as a draft or send it only to yourself.
