## Find the right output

1. **Stay in the selected Cowork project.** Confirm the project/folder you used for the request. Do not search a similarly named project.
2. **Read the run outcome.** Working, a live question, operator gate, failed and completed are different states. Answer a question or ask the operator as directed; do not start duplicate work while waiting.
3. **Use the link Cowork returns to the actual available deliverable.** The current plugin should also link the project's `START-HERE.md` stakeholder dashboard. This is a file inside your selected OneDrive/SharePoint project, not this course's orientation page.
4. **If you need to browse the project:** open that `START-HERE.md`, look under Available deliverables and follow the relevant link. The full stakeholder view is `library/deliverables.md`. Supporting research/plans/reviews are separate from primary deliverables.
5. **Match the requested output label and actual run.** Open the original artifact containing that label/section, from the request you just made. Ask for its actual run ID, artifact identity/source version and canonical project-relative path if they are not visible.
6. **Check availability and review state.** Use a verified current mirror. A retrieval-pending, stale or conflicting file is not the current verified version. An unapproved draft can be read for review; verified storage does not mean business acceptance.
7. **Record the exact reference in your receipt.** Keep the label, actual run ID, artifact/version, original path/link and observed statuses. Do not copy a timestamp-shaped filename from an example.

The deliverable may be one file containing several sections, or a group of files. Open the section or files that actually meet the requested content. Do not assume the correct artifact is named `artifact.md`, the newest file, a BRD, or the first search result.

A label echoed in a request, activity journal or technical index is not the requested deliverable. Check that the linked original actually contains the substantive brief/design/handoff and belongs to the correct run.

If you used an earlier prompt without an output label, ask Cowork to locate its original by the real run and required content. You may record the course label as a worksheet mapping once provenance/content are verified; do not rename or rewrite the original merely to add the label.

The library is navigation to original files. It does not make a new copy of each deliverable. You should not have to manually inspect `.copilot-tracking` or tool transcripts to find the answer.
