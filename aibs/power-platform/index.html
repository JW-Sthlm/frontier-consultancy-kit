Before implementation

Capabilities are choices, not a checklist.

Should an inspection app capture photos offline? Must checklists be versioned? Does a supplier contact represent more than one legal entity? HVE helps you evaluate the need and the data consequences.

Technology-specific, not code-centric.
Canvas mobile/offline, model-driven casework, flow routing, agent knowledge/actions, Pages self-service, custom workbench interaction and BI grain/lineage shape different decisions. Coding capability is not the objective of these exercises.

Live HVE uses the connected Cowork project and actual returned artifacts. Supplied client interviews/design-review findings are fictional; no app implementation or runtime success is implied.
