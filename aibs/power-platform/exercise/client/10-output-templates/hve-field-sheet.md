## Constraint delivery and action truth

Instruction set, constraint register and harness must each have owner, version and expiry. For every executor call, record request ID, attached in-scope constraint IDs/versions, excluded scope and returned ACK evidence. An ACK proves receipt only, not compliance, approval or enforcement. Missing/stale/wrong-scope ACK means HOLD the governed work.

If using a plugin, record actual enabled tools and version, authoritative project folder and operator role. An unavailable/disabled tool is BLOCKED with its actual capability/denial evidence or an explicit not-invoked status. Never invent a plugin result, stage completion or gate release. Desk simulations stay separate from live tool records. No plugin is presumed installed by this field sheet.
